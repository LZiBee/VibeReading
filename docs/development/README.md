# 开发规范索引

本目录存放给 AI 和开发者看的项目实现规范。

- `code-area.md`：代码区说明，规定文件夹职责、模块边界和新文件放置规则。
- `logging-standard.md`：日志记录规范，规定进度、报错、决策分别保存在哪里，以及怎么写。
- `versioning-and-commits.md`：仓库、版本号、提交信息、提交记录和发布流程规范。
- `ui-naming.md`：当前桌面端工作台 UI 命名索引，统一记录各区块名称、层级 ID 和代码锚点，方便按名字指定修改区域。
- `ui-style-guide.md`：当前桌面端 UI 规范，统一记录默认视觉风格、交互尺度和不推荐的样式方向。
