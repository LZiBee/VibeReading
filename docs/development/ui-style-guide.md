# UI 规范

本文档记录本项目默认的界面风格要求，后续所有桌面端 UI 设计和改动优先遵守这里的约定。

## 核心印象

- VS Code 式工作台
- 扁平化
- 简洁克制
- 工具型界面
- 高信息密度
- 编辑器感

## 关键词

- 扁平
- 低装饰度
- 低饱和
- 轻边框
- 弱阴影
- 分隔线驱动
- 选中态低调
- 文本优先
- 规整
- 紧凑
- 专业

## 视觉原则

1. 不做营销页感，不做花哨装饰。
2. 不依赖大卡片、重阴影、强渐变、强圆角。
3. 用间距、层级、边线和文字状态组织信息。
4. 选中状态优先用浅底色、细竖条、文字高亮表达，不用粗框。
5. 页面整体保持安静、克制、耐看。

## 组件约定

- 列表行优先，少用浮夸卡片。
- 工具栏保持紧凑，按钮尽量图标化。
- 面板之间用清晰分隔线区分。
- 重要区域可有轻微底色区分，但不要抢视觉中心。
- 当前内容、当前标签、当前条目必须一眼可辨，但不张扬。

## 交互约定

- Hover 要轻，不要跳。
- Focus 要清晰，但要收敛。
- Selected 要可见，但别像被框住。
- Disabled 要明显降权。
- 空状态要简洁，避免大段说明文。

## 推荐写法

- `扁平化、克制、专业、编辑器式、低装饰度、高信息密度`
- `选中态低调，用浅底色和细竖条表达`
- `不要卡片化，不要重阴影，不要大圆角`

## 不推荐

- 营销型首页
- 大面积渐变背景
- 浮夸卡片堆叠
- 强阴影和强玻璃拟态
- 明显粗边框选中框
- 过度圆润和装饰性元素

## 默认判断

如果没有额外说明，后续 UI 修改默认按以下顺序理解：

1. 先保证信息清晰
2. 再保证结构规整
3. 最后才做视觉修饰
