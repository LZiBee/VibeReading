# MinerU 仓库链接抽取策略

- 日期：2026-05-24
- 状态：已采用
- 背景：需要识别论文中是否提供 GitHub 代码仓库链接，用于后续拉取仓库并做论文-代码对齐分析。
- 方案：不依赖 MinerU 的特殊链接节点，优先扫描 MinerU 输出文本中的 URL，重点读取结果 zip 里的 `full.md`，并用 `github.com` 正则抽取候选仓库链接。
- 取舍原因：实测 `HQ-SAM` 的仓库链接在 MinerU 的 `full.md`、`content_list_v2.json`、`layout.json` 中表现为普通文本，没有稳定的特殊链接标记；直接扫描文本输出更简单且更稳。
- 影响范围：论文导入后的仓库链接识别、后续代码仓库拉取、论文-代码对齐候选生成。
- 后续动作：后续可在抽取后增加上下文窗口和白名单/黑名单判断，用于区分论文主仓库、依赖仓库和参考项目仓库。
